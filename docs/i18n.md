# Translation (i18n)

Locabase ships in **English** (default) and **Azerbaijani**. The choice lives in
Settings, is stored in `localStorage`, and survives restarts.

There is no i18n library. Two parallel dictionaries and a dotted-key lookup:

```
src/renderer/src/i18n/
  index.tsx        the provider, `t()`, `tDynamic()`, `useT()`, `useI18n()`
  types.ts         `Dict` and the `Keys<D>` dotted-key type
  locales/az.ts    the source language
  locales/en.ts    English
```

```tsx
const t = useT()
t('sync.computedAt', { time: '2 minutes ago' })
```

## How lookup works

`t('a.b.c')` reads the active dictionary, and falls back to `az.ts` if the key is
missing there. `TranslationKey` is derived from the shape of `az.ts`, so an
unknown key is a **build error**, not a silent blank.

`tests/i18n.test.ts` asserts that the two dictionaries have exactly the same key
set and that no value is an empty string. Leave a translation gap and the test
turns red.

## Adding a string

1. Add the key to `locales/az.ts`.
2. Add the same key, in the same position, to `locales/en.ts`.
3. Use it: `t('yourSection.yourKey')`.

Interpolation uses `{name}` placeholders and a `vars` object.

## Adding a language

1. Copy `locales/en.ts` to `locales/<code>.ts` and translate the values.
2. Register it in `LOCALES` and `DICTS` in `index.tsx`, and widen the `Locale`
   type.
3. Extend `tests/i18n.test.ts` to cover the new dictionary.

Write the language's own name as its label (`Azərbaycan`, not "Azerbaijani").

## `config.toml` field labels

The 108 `config.toml` field labels live in
[`src/shared/config-schema.ts`](../src/shared/config-schema.ts) as Azerbaijani
source strings, because that file is imported by the **main** process too and
must not depend on the renderer's translation layer.

The renderer overlays translations on top of them, under
`config.fields.<path>.label` and `config.fields.<path>.help`. Those paths contain
dots and come from data, so they use `tDynamic()` rather than `t()` — the static
`TranslationKey` check cannot apply to them. When no overlay exists, the
Azerbaijani source text is shown.

Auth provider metadata works the same way: `src/shared/providers.ts` holds only
`id`, `label`, `fields` and `docs`; the explanatory `hint` for each provider is a
translation key (`auth.providerHint.<id>`).

## What is deliberately not translated

- **Code comments and identifiers** — English only, everywhere.
- **Output from external processes** — `supabase`, `docker`, `psql` and `ssh`
  write their own messages into the log panel. Those are their words, not the
  app's, and translating them would make them harder to search for.
- **Relative timestamps** — `timeAgo()` uses `Intl.RelativeTimeFormat` with the
  active locale. "3 minutes ago" is grammar, not copy, so it does not belong in
  the dictionaries.
